📡 Telecommunication Database Management System

A SQL-based project focused on managing and querying telecommunication data using relational database concepts.

📌 Project Overview

The Telecommunication Database Management System is designed to organize telecom-related information, including customer details, recharge plans, payments, call records, SMS records, internet usage, and tower information.

This project uses SQL queries to retrieve, filter, combine, and summarize data across related database tables.

🛠️ Technologies Used

- 💾 MySQL
- 🗃️ SQL


✨ SQL Concepts Covered

- 🔍 **Basic Queries:** `SELECT`, `WHERE`, `DISTINCT`, `LIKE`, `BETWEEN`, `IN`, `IS NULL`, and `ORDER BY`
- 🔗 **Joins:** `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN`
- 📊 **Grouping and Aggregation:** `GROUP BY`, `HAVING`, `COUNT()`, and `SUM()`
- 🔀 **Combining Results:** `UNION`
- 🧠 **Conditional Expressions:** `IF()` and `CASE`
- 🔎 **Subqueries:** Subquery using `ANY`
- 👁️ **Views:** Creating and querying a database view using `CREATE VIEW`
- 🧩 **Database Relationships:** Primary keys and foreign key constraints

## ⚙️ How to Run

1. Install MySQL Server and MySQL Workbench.
2. Download or clone this repository.
3. Open the `.sql` file in MySQL Workbench.
4. Execute the database, table creation, and data insertion statements in order.
5. Run the individual SQL queries to explore the data.

🎯 Project Objective

The objective of this project is to gain practical experience with SQL queries and relational database concepts through a telecommunication-based dataset.

📚 Learning Outcomes

- Understanding relational database table structures.
- Creating tables with primary and foreign key constraints.
- Retrieving and filtering records using SQL.
- Combining information from multiple tables using joins.
- Grouping records and applying aggregate functions.
- Practising conditional expressions, subqueries, and views.
